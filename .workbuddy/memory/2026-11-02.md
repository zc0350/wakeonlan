## 数据源从 SQLite 迁移到 JSON（用户需求：数据量小）
- `internal/db/db.go` 全部重写为单 JSON 文件存储（`{"devices":[...],"admins":[...]}`）：
  - `sync.Mutex` 串行化所有方法；数据常驻内存，写操作全量重写落盘。
  - 原子写：先写 `<path>.tmp` 再 rename；每次落盘前把上一版备份为 `<path>.bak`。
  - 文件权限 0600（含 bcrypt 哈希）；解析失败时快速报错并提示恢复 .bak。
  - Store 方法签名保持不变，handler/main 几乎零改动。
- 附带修复：UpdateDevice 现在回填 CreatedAt（原 SQLite 版返回零值）；管理员重复用户名改用 `db.ErrDuplicate`（原来是 `strings.Contains(err, "UNIQUE")` 的 hack）。
- config：新增 `WOOL_DATA_PATH`，兼容旧 `WOOL_DB_PATH`；默认 `wol.json`。service 文件同步更新。
- 依赖移除 modernc.org/sqlite，go.mod 只剩 golang-jwt + x/crypto。
- 体积：Linux 11.4MB → 7.1MB（-38%），Windows 17MB → 10.5MB。json/encoding 本来就在用，无额外增量；net/http 占大头。
- 冒烟测试 24 项全过：登录/设备增删改查（含逗号引号备注往返、created_at 保留）/单台+批量唤醒/重复用户名 409/密码重置与修改/删自己与删最后一个管理员防护/重启后持久化。.bak 备份正常生成。

## server 配置段（端口 + JWT 密钥进 JSON）
- wol.json 新增顶层 `server` 段：`{"listen": ":25352", "jwt_secret": "..."}`，db 层 ServerConfig 读写，落盘自动保留。
- 监听地址优先级：WOOL_LISTEN_ADDR 环境变量 > server.listen > config.DefaultListenAddr（默认 **:25352**，用户指定，不要用 8080）。支持纯端口号写法（自动补冒号）。
- JWT 密钥优先级：WOOL_JWT_SECRET 环境变量 > server.jwt_secret（缺失时用 crypto/rand 生成 64 位 hex 并持久化）。已删除 IsDefaultSecret 与"不安全默认密钥"告警；env 密钥不落盘（omitempty）。
- 好处：密钥跨重启稳定，重启不再使已登录用户失效。
- service 文件：WOOL_LISTEN_ADDR / WOOL_JWT_SECRET 均改为注释掉的可选项，默认全部走 wol.json。
- 冒烟验证：默认端口 25352、纯端口规范化、env 覆盖、写操作后 server 段保留、密钥自动生成且重启后旧 token 仍有效（200）、env 模式下文件无 jwt_secret 字段。

## 局域网扫描 + 批量添加设备
- 新增 `internal/lan` 包：UDP 探测（DialTimeout+SetWriteDeadline 各 300ms，128 并发）触发内核 ARP 解析 → 读 ARP 表（unix: /proc/net/arp 优先、回退 arp -an；windows: 解析 arp -a，正则匹配数据行）。全程无需 root。
- 自动检测本机 /24 网段（net.InterfaceAddrs，排除回环/链路本地），也支持 ?cidr= 指定；单次上限 4096 主机。
- 反向 DNS 主机名：系统解析器，单查询 ctx 800ms + 整阶段 2s 硬帽（goroutine 等待 select 超时）。**关键教训：Windows 上 UDP Write 到不可达路由会长时间阻塞，必须 SetWriteDeadline；系统解析器对无 PTR 的局域网 IP 会拖 12s+，必须硬帽**。最终两个 /24 全量扫描 ~2.7s。
- MAC 规范化：model.NormalizeMAC/EqualMAC（大写冒号形式）；扫描结果按 MAC 去重、过滤广播/组播 MAC。
- API：GET /api/lan/scan（返回 hosts 带 exists 标记）、POST /api/devices/batch（重复/非法 MAC 跳过，上限 500，返回 created/skipped）。
- 前端：设备页"扫描局域网"按钮 → 弹窗（打开即自动扫描）→ 复选框表格（已存在默认不勾）→ 一键添加选中。
- 实测：真实局域网发现 10 台、主机名 2 个；批量 4 条 → created=2 skipped=2（重复+非法）；小写连字符 MAC 正确规范化；唤醒正常。Linux 二进制 7.5MB。

## 唤醒发包参数可配置（次数/间隔进 wol.json）
- `server` 段新增 `wake_attempts`（默认 3）与 `wake_interval_ms`（默认 100）；缺省/<=0 时启动自动补写默认值（旧数据文件无此二字段同样自愈）。
- wol 包：新增 `Options{Attempts, Interval}`，`Wake(mac, broadcast, opts)`；默认值常量 `DefaultAttempts=3`、`DefaultInterval=100ms` 定义在 wol 包（单一真源，db 引用）；防呆：次数上限 20、间隔上限 5s（Options 内部 clamp）；最后一发后不再 sleep（省 100ms/台）。
- db：`ServerConfig` 增加两字段（无 omitempty，保证文件可见），`WakeConfig()` 访问器带零值回退；handler `wakeOptions()` 组装 Options，单台/批量唤醒共用。
- 实测：全新文件自动写入 3/100；手改 5/200 重启保留且生效（写操作不破坏配置）；非法值 0/-50 启动自愈回 3/100。双平台二进制已重新编译。
