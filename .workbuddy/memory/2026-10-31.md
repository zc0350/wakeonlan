# 2026-10-31

## 项目：Wake-on-LAN 管理系统（Go）
从零搭建了一套 Go 语言 WOL 管理后台，已完成编译与接口冒烟测试。

- 技术栈：Go 1.27，标准库 net/http（1.22+ 路由），modernc.org/sqlite（纯 Go，无 cgo），golang-jwt/jwt/v5，golang.org/x/crypto/bcrypt。
- 目录：main.go（入口+embed 静态资源）、internal/{config,model,db,wol,auth,handler}、web/{templates,static}。
- 功能：设备管理（增删改查 + 单台/批量唤醒）、多管理员（增删 + 重置他人密码 + 修改自己密码）、JWT 登录（HttpOnly Cookie，同时支持 Bearer）。
- WOL：构造 102 字节魔术包，经 UDP 广播（SO_BROADCAST，跨平台 build tag），每设备连发 3 次。
- 默认管理员 admin/admin123（首次启动建库时创建，可通过环境变量覆盖）。
- 配置环境变量：WOOL_DB_PATH、WOOL_LISTEN_ADDR、WOOL_JWT_SECRET、WOOL_DEFAULT_ADMIN、WOOL_DEFAULT_PASSWORD。
- 构建：`go build -o wol-server.exe .`；运行：`./wol-server.exe` 后访问 http://localhost:8080/。
- 注意：本机测试时 curl 需加 `--noproxy '*'` 绕过本地代理才能访问 127.0.0.1。

## Linux 部署支持（追加）
- 跨平台 build tag：`internal/wol/broadcast_windows.go`(windows) / `broadcast_unix.go`(!windows)，Linux 走 unix 版 SO_BROADCAST。
- 交叉编译命令：`GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o deploy/wol-server-linux-amd64 .`，已编译出 11MB 静态二进制（modernc sqlite 纯 Go 无 cgo，无需系统依赖）。
- 已生成 `deploy/wol-server.service`（systemd 单元，含环境变量配置）与 `deploy/install.sh`（一键建用户/装服务/开机自启）。
- 部署要点：Linux 上发广播 UDP 不需 root；服务运行用户 wol，数据目录 /opt/wol；务必改 WOOL_JWT_SECRET。
